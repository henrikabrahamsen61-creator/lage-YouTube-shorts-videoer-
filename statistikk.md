# YouTube-statistikk

Fyll inn tallene fra YouTube Studio (Analyse → velg Shorts-klippet) ca. 24–48 timer etter opplasting.
Boten leser denne filen før den lager et nytt klipp, og bruker tallene til å justere hook, lengde og tema.

| 002-gta6-mistakes | | | | | | Første med nye hook-regler |

## Slik leser boten tallene
- **Viewed vs. swiped away under 60 %:** hooken er for svak. Endre første bilde, første setning eller hook-tekst.
- **Snitt visningstid under halve lengden:** klippet er for langt eller midtpartiet er tregt. Kort ned og kutt raskere.
- **Mange abonnenter per visning (over 1 %):** temaet treffer. Lag flere klipp om lignende ting.
- **Sammenlign alltid** med de forrige klippene, ikke bare med målene over.
